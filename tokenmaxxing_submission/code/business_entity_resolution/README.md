# Business Entity Resolution — tokenmaxxing

Pipeline for the Amazon ML Challenge 2026 entity-resolution task: for every Source-1 (S1) business
record, find all Source-2 / Source-3 records describing the same real-world business. Scored by
macro F0.5 per S1 entity.

## Pipeline

```
 raw TSVs ──► preprocess.py ──► dataset_processed/        (normalisation, abbreviation expansion,
                                                            Indic transliteration, house / legal parsing)
             │
             ▼
 e5-large fine-tuned (contrastive, hard negatives)  ──► FAISS top-20 per S1, within country
             │                                          (pair recall@20 = 99.9 %)
             ▼
 mDeBERTa-v3 cross-encoder reranker  ("name | address" pairs, yes / no)
             │
             ▼
 stage-2 ensemble  LightGBM + XGBoost + CatBoost on 50 features
 (scores, rank / gap in the S1 list, competition between S1s for a record, house / legal / name / address)
             │
             ▼
 decision: threshold + each S2/S3 record to at most one S1  (+ France-specific rules)
             │
             ▼
 matching_results.tsv  +  candidate_pairs.tsv  ──► validate_submission.py: PASS
```

Both models are open-weight and MIT/Apache-2.0 licensed, well under the 8B parameter cap
(e5-large ≈ 560M, mDeBERTa-v3-base ≈ 280M). No external data, APIs, or lookups are used anywhere in
the pipeline — only the provided train/test TSVs.

## Files

| File | Stage |
|---|---|
| `src/preprocess.py` | normalisation, abbreviation expansion, Indic transliteration, house/legal parsing |
| `src/retrieval_experiments.py` | base embedding models, FAISS candidate search, recall evaluation, train/val split |
| `src/finetune_e5.py` | hard-negative mining + contrastive fine-tuning of e5-large |
| `src/train_reranker.py` | mDeBERTa-v3 cross-encoder: candidate building, training, prediction, evaluation |
| `src/error_analysis.py` | false-positive / false-negative pattern analysis of the reranker |
| `src/stack_lgbm.py` | stage-2 feature engineering + macro-F0.5 decision-threshold search |
| `src/stack_models.py` | LightGBM / XGBoost / CatBoost / MLP / logistic-regression stage-2 models and ensembles |
| `src/full_pipeline_v1.py` | end-to-end test-set run: retrieval + reranker → submission |
| `src/full_pipeline_v2.py` | end-to-end test-set run: + stage-2 ensemble |
| `src/postprocess_v2.py` | fix / merge / France-specific postprocessing variants |
| `src/validate_submission.py` | official submission-format validator |
| `src/eda.py`, `src/analysis/` | exploratory analysis and report generation |

## Reproducing

```bash
pip install -r requirements.txt
# place the challenge kit at student_resource/dataset/{train,test}/... (not included here)

python src/preprocess.py
python src/retrieval_experiments.py
python src/finetune_e5.py mine && python src/finetune_e5.py train && python src/finetune_e5.py eval
python src/train_reranker.py cands_ft && python src/train_reranker.py train \
    && python src/train_reranker.py predict && python src/train_reranker.py eval
python src/stack_lgbm.py features && python src/stack_models.py
python src/full_pipeline_v1.py --gpus 0,1,2,3,4,5,6,7
python src/full_pipeline_v2.py all
python src/postprocess_v2.py france
python src/validate_submission.py --matching output/matching_results.tsv \
    --candidate output/candidate_pairs.tsv --test-dir student_resource/dataset/test
```

Tested on 8x V100 32 GB, 40 CPUs, 500 GB RAM (Python 3.11, CUDA 12). Fine-tuned model weights and
stage-2 model files are not included in this package; the scripts retrain them from the challenge
data. Large intermediate artifacts (embeddings, candidate lists, features) are cached under
`experiments/` and are not required to be kept — every stage regenerates them.

**Note on `output/candidate_pairs.tsv`:** this package ships the final `matching_results.tsv`.
`candidate_pairs.tsv` is an intermediate artifact of the retrieval stage (`retrieval_experiments.py`
/ `full_pipeline_v1.py`) and is regenerated by rerunning the pipeline above against the challenge
data, since it is not persisted as a standalone deliverable in this snapshot.

## Results (80/20 hold-out of train, by S1)

| Stage | Metric | Value |
|---|---|---|
| Retrieval, base e5-large | pair recall @10 / @100 | 96.7 / 98.2 |
| Retrieval, fine-tuned e5-large | pair recall @10 / @20 / @50 | 99.8 / 99.9 / 100.0 |
| Cosine threshold + assignment | macro F0.5 | 0.9583 |
| Reranker + assignment | macro F0.5 | 0.9831 |
| Reranker + assignment + abstain rule | macro F0.5 | 0.9914 |
| Stage-2 ensemble, 50 features | macro F0.5 | 0.9939 |
